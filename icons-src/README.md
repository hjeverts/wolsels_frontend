# Iconen

Bron voor favicon, app-iconen en het Apple touch icon: het Material Symbols-symbool "gesture" (hetzelfde als
het logo in de werkbalk), wit op de primaire themakleur `#026e00`.

| Bron                | Gebruikt voor                                             |
|---------------------|-----------------------------------------------------------|
| `icon.svg`          | `favicon.svg`, `icon-192.png`, `icon-512.png`             |
| `icon-small.svg`    | `favicon.ico` (16/32/48 px, groter symbool voor leesbaarheid) |
| `icon-apple.svg`    | `apple-touch-icon.png` (180 px, volledig gevuld)          |
| `icon-maskable.svg` | `icon-maskable-512.png` (Android, symbool in veilige zone) |

Opnieuw genereren: `./icons-src/generate.sh`
